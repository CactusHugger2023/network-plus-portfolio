
# Network+ Learning Portfolio

## About This Project
This repository documents my preparation for the CompTIA
Network+ certification and my development of practical IT skills.

## Objectives
- Understand networking fundamentals and protocols.
- Practise IP addressing and subnetting.
- Build and document simulated networks.
- Develop troubleshooting and diagnostic skills.
- Maintain clear technical documentation using GitHub.
